# Published GPR writing import

Imported October 22, 2026, at the owner's request. The authoritative publication filter was `published === true && draft !== true` in GPR's data/app/articles.json. Four articles qualified; draft routes were not treated as publication evidence.

All four appear in Civic, ordered by original publication date. Legal remains reserved for law-focused essays and study notes; these articles primarily explain assessment and property-tax processes for residents.

The personal site hosts static reading editions. Authorial wording, source citations, dated context, and substantive lists/tables are retained. Application controls, decorative SVGs, media players, and GPR layout are omitted. Animated tax-roll lessons use their authored setup, result, observation, explanation, and takeaway data in the same order. Calculators and interactive charts link to their original GPR versions rather than presenting nonfunctional controls. The source article links also retain access to original media and guides. This is a presentation adaptation, not a new review of the legal or tax guidance.

Rendered source snapshots, selected published metadata, source URLs, and SHA-256 hashes are stored in _sources/writing/gpr and excluded from the public site build. GPR files were only read. No synchronization, GPR edits, publication, or commit was performed.

Verification: production build, 68-page artifact/link checks, published-only regression test, and browser review of the writing index and imported article template. Source code and launch evidence still require the ordinary release review; earlier fingerprint-bound approvals become stale after this content addition.
